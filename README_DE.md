# NeoSkill Client

Deutsche Dokumentation. English version: [README.md](README.md)

NeoSkill ist ein CS2-Client mit Website-Login, Abo-Modulen (Radar / Glow / Aimbot / Full), Live-Web-Radar und mehrsprachigem Menü.

**Website:** [https://sparrebell.de/radar/](https://sparrebell.de/radar/)

---

## Funktionen

- Login mit Website-Account
- Freischaltung je nach Plan (Radar, Glow, Combat, Full)
- Live-Radar-Raum für Zuschauer im Browser
- Sprachauswahl im Menü: **Deutsch, English, Français, Español, Türkçe, Polski, Русский**
- Schnell-Buttons über dem Login: **Startseite · Preise · Registrieren**

---

## Schnellstart

1. Account erstellen: [Registrieren](https://sparrebell.de/radar/register.php)
2. Plan wählen: [Preise](https://sparrebell.de/radar/pricing.php)
3. Download von der Website unter **Downloads** (oder Dateien aus `release/` nutzen)
4. CS2 starten
5. `release/START.bat` oder `release/injectieren.bat` **als Administrator** ausführen
6. **EINFÜGEN (INSERT)** drücken → NeoSkill-Menü öffnet sich
7. Mit Website-Username + Passwort einloggen
8. Unter **Account → Sprache** die gewünschte Sprache wählen

### Paketinhalt (`release/`)

| Datei | Beschreibung |
|-------|----------------|
| `NeoSkill.dll` | Client-Modul |
| `NeoSkillInject.exe` | Injector |
| `injectieren.bat` | Start-Hilfe (Admin-Rechte) |
| `START.bat` | Kurzstart für die Injection |

## Sprachen

Die UI-Sprache stellst du unter **Account → Sprache** ein. Die Auswahl wird lokal gespeichert und beim nächsten Start wiederhergestellt.

Unterstützt: Deutsch, Englisch, Französisch, Spanisch, Türkisch, Polnisch, Russisch.
